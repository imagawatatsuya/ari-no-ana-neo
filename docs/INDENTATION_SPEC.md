# 字下げ仕様

## 基本方針

- `Novel.body` は投稿時の本文原文をそのまま保存する。
- 自動字下げは閲覧・プレビュー時の表示用コピーにだけ適用する。
- 全角スペースを含む手動の字下げ、とくに二字以上の字下げは作者の表現として削除・縮小・正規化しない。
- 脚注定義は本文から分離してから自動字下げを適用し、脚注見出し・脚注本文・脚注リストには適用しない。

## 投稿者設定

`Novel.authorIndentMode`（Supabase では `author_indent_mode`）に次を保存する。

| 値 | 意味 |
|---|---|
| `none` | 自動字下げを望まない |
| `jisage` | 日本近代文学の慣習に沿う自動字下げを望む |
| `raw` | 旧投稿・API互換用。原文どおりに表示し、手動字下げを保持する |

新規投稿画面では `none`（自動字下げなし、手動空白は保持）または `jisage` を選び、入力画面とプレビュー画面で確認できる。`raw` は旧投稿・互換入力を表す内部値で、読者への強制設定ではない。

## 読者設定

`bunsho_reader_preferences_v1` の `indentMode` に保存し、既定値はサイト慣習に合わせて `none` とする。

| 値 | 表示 |
|---|---|
| `none` | 自動字下げなし。手動の空白は保持する |
| `jisage` | 投稿者設定にかかわらず自動字下げする |
| `author` | 投稿者設定に従う |

読者設定を表示上の最終決定とする。したがって、作者が `jisage` でも読者が `none` を選べば自動字下げは表示しない。読者が `author` を選んだ場合だけ作者の `authorIndentMode` を参照する。

## 旧投稿と将来更新

- `authorIndentMode` がない既存投稿は `raw` として扱う。本文データの一括移行はしない。
- `jisage-core` は `package.json` で特定コミットに固定する。
- `services/jisageAdapter.ts` にサイト固有の除外規則と読者・作者モードの優先順位を集約する。`jisage-core` 更新時はこのアダプターのテストを先に確認する。
- Supabase では `supabase/migrations/20260812_author_indent_mode.sql` を先に適用する。未適用の旧DBでは投稿自体を継続できるが、`jisage` の投稿者設定は保存できず、投稿後に警告する。

## 検証項目

- 作者設定 `none` / `jisage` のプレビューと投稿 payload、旧値 `raw` の互換処理
- Supabase移行前の互換投稿と、`jisage` メタデータ未保存時の警告
- 読者設定 `none` / `jisage` / `author` の優先順位とブラウザ保存
- メタデータのない旧投稿の `raw` フォールバック
- 二字以上の手動字下げの保持
- 脚注本文への非適用
